## Essays and synthesis

**Geethapriya Setty (a regulatory affairs manager at a medical device company, writing personally, on Atlan's vendor-hosted Context and Chaos) argues that a past decision is precedent, not authority, and must pass three gates before an agent reuses it.** The gates cover what the decision can establish, whether its reasoning can be inspected, and whether the system can safely take in new context. Her prototype used about 25 invented assessments and matched her own judgments 75 to 80% of the time after heavy correction. It adds a regulated-industry limit to the "decision traces" idea that context-layer vendors sell. Her own judgment is the only benchmark, and "controlled context lag" is named without evidence. Published November 12. [Context and Chaos](https://contextandchaos.substack.com/p/ai-agents-and-precedent-three-gates). ^essay-precedent-three-gates

**George Fraser, Tristan Handy and Taylor Brown (Fivetran executives, a vendor; Handy is a dbt Labs co-founder) argue that agents are "intelligence plus tools and data", that knowledge work goes first, and that it needs open data infrastructure.** It shows the dbt and Fivetran stack arguing as one company for open infrastructure, a counterpart to Atlan's open registry case of November 5. The one number, "50x more question/answer loops", has no source, it generalizes from software to all knowledge work, and the portability argument serves Fivetran's platform. Published November 11. [Fivetran](https://www.fivetran.com/blog/founders-letter). ^essay-fivetran-founders

**Jakub T. Jankiewicz (independent blogger) argues that purely AI-generated code should be released as open source or dedicated to the public domain.** Models trained on open code and Creative Commons answers, and output with no human author may not be copyrightable, so closed licensing is "license laundering". It ties training-data provenance and authorship into one rule a team could write into policy. The Monkey Selfie and Wikimedia analogies are not code precedent, and he sets no threshold for "purely". The page is undated; Hacker News submitted it November 15 (1,197 points). [Jankiewicz](https://jakub.jankiewicz.org/blog/ai-code-open-source/). ^essay-ai-code-open-source

**Matteo Raso (independent blogger who says he applied for a Liberal Party of Canada nomination) argues the AI bubble probably does not exist, because the spend is mostly one-time construction.** Running costs are modest, revenue is growing, and Alphabet and Meta trade at price-to-earnings ratios in the 20s, unlike dot-com firms. It is a numbers-first counter to the "no payoff" items of November 6. His figures are rough and partly uncited, and he treats an OpenAI failure as a limited risk. The thread has 974 comments, the most disagreement of the window. Published November 8. [Raso](https://matteoraso.github.io/im-not-convinced-the-ai-bubble-exists.html). ^essay-ai-bubble

## Data engineering

**Databricks says Genie Ontology is generally available (release note November 9, blog November 11), and its benchmark shows 91% against 45% and 58% for two unnamed frontier agents.** Genie extracts learned "snippets" from dashboards, queries and notebooks, scores each by source, use and freshness, and ranks modeled knowledge such as metric views above them. The benchmark used an invented energy supplier workspace, so it is vendor-run. A Databricks employee wrote on August 4 that there is "not yet a full reviewable changelog", and the announcement does not mention Apache Ossie. Read: watch. A regulated workload needs a reviewable change log and an export path first. [Databricks](https://databricks.com/blog/announcing-ga-genie-ontology). ^de-genie-ontology

**Snowflake made semantic view materializations generally available (November 11) and put many-to-many relationships in preview (November 13), and each has a carve-out.** Rewrites apply only to Semantic Structured Query Language (SQL), so Cortex Analyst and Cortex Agents do not benefit. `CREATE OR REPLACE SEMANTIC VIEW` drops every materialization, and the docs give no refresh billing. Many-to-many paths cannot use level of detail metrics. Read: watch many-to-many; test materialization staleness and refresh-warehouse cost on one slow view first. [Snowflake](https://docs.snowflake.com/en/release-notes/2026/other/2026-11-11-semantic-view-materializations-ga). ^de-semantic-view-materializations

Read: adopt a check that continuous integration and container images run Python 3.11 or later. [PyPI](https://pypi.org/pypi/dagster/json). ^de-python-floor

**Databricks put Genie ZeroOps and Lakehouse//RT in Beta on November 12.** ZeroOps writes root-cause analyses and proposes fixes, and states no cost. ## Enterprise platform

**Amazon Web Services (AWS) documents three terms on Claude Fable 5.2 and Mythos 5.2 that change integration code.** A classifier refusal returns HTTP 200 with `stop_reason: "refusal"`, to be handled "as a primary response path". Fable 5.2 requires `aws_review` data retention. Output burndown against quota is 10x for Fable 5.2 and 2.5x for Mythos 5.2, and neither supports In-Region routing. Read: adopt after three checks: refusal handling in client code, the retention choice with your data owner, and quota math at 10x with a high `max_tokens`. **AWS says AgentCore Runtime V2 became the default for new runtimes on November 12, with 75th-percentile session start under 2 seconds on a 2 GB image against 29.7 seconds before (vendor-reported).** Existing runtimes stay on V1 until `platformVersion` is set to `V2`. A Classmethod test from September 19, before the switch, found faster cold starts but a slower first call on an existing runtime (1.912 s against 0.611 s) and creation near 188 seconds against 5. AWS's own guide says a snapshot is taken on the first healthy `/ping`, so startup values are shared across restores. Read: adopt for large images or long multi-turn sessions, after moving per-request state out of startup code. [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/new-agentcore-runtime-default/). ^ep-agentcore-runtime-v2

**LiteLLM marks its November 15 post-attack commitments done, and its 1.111.0-dev.4 build changes two defaults.** The table carries no change dates, so the statuses are self-reported. Read: adopt 1.108.9 on the long-term-support line; recheck redaction and cosign identity checks when 1.111 leaves dev. [LiteLLM](https://docs.litellm.ai/blog/security-changes-after-oct-21-2026). ^ep-litellm

**Qdrant 1.20.1 (November 13) fixes a 1.20.0 regression that made index builds up to 3x slower on many-core hosts, and 1.20.2 (November 16) restores the classic build by default.** Read: adopt 1.20.2, and test internal authentication first if you run an API key. ## Agent and context techniques

**Amazon says replacing Claude Sonnet 4.6 with its Strands Decider model on a 20-label ticket-routing job "performed just as well at 98% less cost", and Google shipped a Gemini Decisions API two days later.** Decision models are small models that pick from a closed option list and return probabilities. Amazon gives about \$0.0222 a ticket against \$0.0005, but no volume and no accuracy figure; its live three-way switch with a 45-second rollback is the method to copy. Google's endpoint costs \$0.10 per million input tokens, with accuracy only in charts. Both are vendor numbers. Read: pilot in shadow mode on a closed catalog. [Strands](https://strandsagents.com/blog/amazon-saves-millions-replacing-sonnet-with-strands-decider/), [Google](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/). ^ac-decision-models

**Anthropic says agent memory is four layers kept correct by an offline "dreaming" pass, and its own numbers show wiki representations adding little over search (November 6).** Memory lifted a database task for five of six models. On a 350,000-file corpus wiki plus search scored 61% against 53% for search alone, and on one Harvey task the wiki "showed no clear gain". The post concedes "an incorrect note can be carried into every session". All figures are Anthropic's. [Anthropic](https://www.anthropic.com/research/components-of-agent-memory). ^ac-agent-memory

**The MCP maintainers moved specification releases to a six-month cadence on November 11, with the next on March 30, 2027, and the 2026-07-28 release is unchanged.** The live gap is issue #3394: a lost response on a mutating `tools/call` re-runs the effect. It has 56 comments and no maintainer reply, and one vendor's own server ran an operation three times on the same key. Read: give your own mutating tools a stable operation key and durable result lookup. [MCP](https://modelcontextprotocol.io/seps/3398-release-cycle-updates). ^ac-mcp-cadence-retry

**NVIDIA Auto Ontology reached 13,214 GitHub stars on November 16, up from 8,778 on November 6 (popularity, not quality).** Outside pull requests add MongoDB, SQL Server and Bedrock connectors, but the evaluation repository still publishes no results. [GitHub](https://github.com/NVIDIA/auto-ontology). ^ac-auto-ontology-followup

**Two researchers at Eighth Rank say every Mac builds an undocumented on-device personal knowledge graph, with 181 entity classes and 278 predicates in plaintext SQLite.** This is independent reverse engineering, and only 2 of 17 scorecard columns have a shipped model behind them. It is a deployed context graph with confidence scores and no user correction path, the question vendor context layers face too. [Eighth Rank](https://8rank.ai/game/apple-intelligence-personal-knowledge-graph). ^ac-apple-knowledge-graph

**The Chrome, Edge, Firefox and MDN teams say their Modern Web Guidance skills pack keeps coding agents off outdated web APIs, pruned with evals to drop what models already know.** The README shows no results, and critics note it pushes features Firefox and Safari lack. Take the eval-and-prune loop for your own skills. [GitHub](https://github.com/GoogleChrome/modern-web-guidance). ^ac-modern-web-guidance
