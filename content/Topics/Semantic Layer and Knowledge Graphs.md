# Semantic Layer and Knowledge Graphs

The vocabulary and standards forming around governed metric meaning and structured organizational knowledge: Apache Ossie / Open Semantic Interchange as a portability standard, the "context layer wraps the semantic layer" architectural claim, temporal knowledge graphs (Graphiti) for agent memory, and the three-way stratification into semantic layer / knowledge graph / context layer that several independent vendors converged on describing.
