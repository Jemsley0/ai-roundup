# Agent Memory and Context Engineering

What an agent holds in mind across a long-running task, and the emerging discipline of managing it deliberately: the four-operation context-engineering breakdown (offload, reduce, retrieve, isolate), dedicated memory primitives (Mem0, Letta, Zep, LangMem), the research literature on treating memory as a lifecycle problem rather than a storage problem, and named failure modes like brevity bias and context collapse.
